🔥 全网自动化运维巡检工具

💥 项目简介｜Introduction

告别手动敲命令、手动截图、手动写报告！
这是一款专为网工/运维量身打造的全自动网络巡检工具，基于 Python 原生 GUI 开发，零插件、无广告、纯本地、开源免费。
整合 SSH 批量巡检 + Console 串口巡检 + 批量配置下发 + 自定义命令库 + 一键Word报告生成 五大核心能力，完美替代 Xshell/CRT 人工运维，将数小时工作量压缩至3分钟，是政企机房、变电站、企业内网运维的提效神器！

---
⚡ 炸裂核心能力｜Core Features
🚀 1. 双协议全场景智能巡检
支持市面上99%主流网络设备，一机通吃所有运维场景✨
- 🔐 SSH 批量云巡检：批量导入设备清单，一键批量登录、批量执行命令、批量采集回显，支持 华为 / H3C / Cisco / Linux 全品类设备
- 🔌 Console 本地串口巡检：自动扫描识别COM口，自定义波特率，适配设备离线、无网络本地巡检场景
- 🎨 双模式输出：复刻运维经典黑底绿字仿真截图 + 纯净文本日志双输出，满足归档、核查、上报多种需求
- 🧠 智能回显净化：自动剔除 --More-- 分页、退格乱码、冗余字符，自适应 UTF-8/GBK 双编码，输出内容干净规范
⚙️ 2. 自定义命令分组｜永久持久化
自由定制巡检方案，一次编辑、永久生效💾
- 支持创建多套独立命令分组，按场景、设备、电压等级定制专属巡检库
- 可视化图形化管理：命令新增 / 修改 / 删除 / 重置 全自动本地保存，重启软件零丢失
- 智能文件名清洗，规避Windows非法字符报错，截图、日志100%保存成功
- 内置全套合规巡检模板，覆盖设备状态、资源负载、安全配置、业务配置、硬件状态全维度核查
📤 3. 一键批量配置下发
批量改配置、批量升级、批量调试，解放双手🔥
- 兼容 SSH / Console 双模式批量配置下发
- 支持按设备类型精准过滤，定向执行配置，避免误操作
- 支持多行批量指令、特殊交互指令，实时日志回显，执行状态全程可视
📑 4. 全自动智能报告生成
告别熬夜排版，一秒生成专业运维报告📄
- 基于Word模板智能渲染，自动填充站点、时间、人员、设备信息
- 自动匹配嵌入巡检截图，支持手动替换特殊截图，适配专项核查需求
- 自动时间戳命名、自动保存桌面，格式规范、可直接用于上报、归档、验收
💻 5. 极致丝滑GUI交互体验
零基础上手，全可视化操作，颜值与实力并存✨
- 智能表格编辑：双击改参数、Tab快速跳转、Ctrl+A全选、Shift区间多选，操作丝滑流畅
- 独立双色日志面板，区分SSH/Console日志，运行状态一目了然
- 任务一键启停，杜绝后台冗余进程，资源占用极低
- 内置在线更新检测，实时同步最新版本功能
🛡️ 6. 企业级稳定架构
稳如磐石，批量运行零崩溃💪
- 独创设备连接池，规避重复建连，大幅提升批量巡检效率
- 多线程异步任务架构，后台全速运行，UI界面永不卡顿
- 全链路异常捕获，连接失败、指令报错精准记录，快速排障
- 分层级自动归档，按时间戳创建独立巡检目录，文件规整不混乱
